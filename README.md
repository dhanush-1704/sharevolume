# Share Volume Calculator

A simple and responsive web application to calculate the number of shares you can purchase given a share price and an investment amount.  Built using HTML, CSS (Tailwind CSS), and JavaScript.

## Features

*   Calculates the total number of shares based on the share price and investment amount.
*   Responsive design using Tailwind CSS for optimal viewing on different devices.
*   Clear button to reset the input fields.
*   Input validation to ensure valid numeric values are entered.

## How to Use

1.  Enter the share price in the "Share Price" input field.
2.  Enter the amount you want to invest in the "Investment Amount" input field.
3.  Click the "Calculate" button to calculate the total number of shares.
4.  The total number of shares will be displayed in the "Total Shares" field.
5.  Click the "Clear" button to clear all input fields.

## Technologies Used

*   HTML
*   CSS (Tailwind CSS)
*   JavaScript
